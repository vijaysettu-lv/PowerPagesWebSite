Developer & Testing Pages

Utility pages for development, testing, and diagnostics

Click on any description to expand/collapse details

Page Description
/lvcpdev
Developer Testing Console - Comprehensive development tool with multiple sections
  • User Information: View current user details, roles, branch/region assignments
  • Setup Query Variables: Display all setup query variables (is_admin, userBranchList, etc.)
  • API Calls: Interactive API testing interface with multiple endpoints (Business Central OData, Dataverse, Power Pages), supports GET/POST/DELETE/PUT/PATCH methods, includes headers and POST data configuration
  • JavaScript Functions: Execute various utility functions (web role management, approval deletion, log operations, local storage management)
  • Logs: Query and filter system logs with date range, user, kind, and detail filters
  • Commission Approvals: View recent commission approval records

Primary tool for development, debugging, and API testing.
/lvcpx1
Data Change Detection System - Hash-based monitoring tool for detecting data changes
  • Calculates SHA-256 hashes of table data (branches, periods)
  • Compares current data against stored hashes to detect changes
  • Stores hashes in browser localStorage for comparison across sessions
  • Useful for monitoring when reference data tables are modified
/lvcpx2
Minimal Test Page - Simple placeholder page

Displays "X2". Used for basic page rendering tests or as a template starting point.
/lvcpx3
Entity List Example - Demonstrates entity list functionality
  • Displays text "X3 ex three"
  • Includes embedded entity list: "Rodj All branch lvnCommissionBranches"
  • Shows modern entity list with natural language search enabled

Example implementation of Power Pages entity list component.
/lvxcpquery
Advanced Data Query Tool - Multi-table query interface with date filtering
  • Date Range Selection: Quick presets (last hour, today, last 7/30 days) or custom date ranges
  • Multiple Tables: Query logs, loan officers, commissions, or branches
  • User Filtering: Regex-based filtering with presets to exclude/include specific users
  • Dynamic Schema: Table headers and columns adjust based on selected table
  • API Integration: Uses Power Pages Web API to fetch data dynamically

Ideal for ad-hoc queries and data investigation across different entity types.
/lvxdata
User Activity Report - 30-day user activity analytics and visualization
  • Summary Statistics: Total log entries, unique users, average daily activity, most active day
  • Daily Breakdown: Table view with activity bars showing logs per day
  • User Filtering: Toggle to exclude/include test and admin users (default excludes Loanvisiontesting, Robert Martin, Michael LeBuhn)
  • View Modes: Table view (default) or chart view
  • Server-Side Data: Uses FetchXML to query last 30 days of logs, processes client-side for flexibility

Comprehensive activity reporting for understanding portal usage patterns.
/diag
System Diagnostics & Data Browser - Comprehensive system information and data inspection tool
  • Current User Information: Complete user profile, roles, branch/loan officer assignments
  • Period Data: Full period table with all fields (period number, dates, visibility, codes)
  • Branch Data: Complete branch listing with codes, names, and metadata
  • Loan Officer Data: Full loan officer table with assignments and details
  • Commission Summary: Aggregated commission totals by loan officer, branch, and type
  • Setup Variables: All system configuration variables and user-specific settings

Primary tool for inspecting system data, verifying configurations, and troubleshooting data-related issues.
/_services/about
Power Pages System Diagnostics - Built-in Microsoft portal information page
  • Portal Details: Version, build number, Portal ID, Organization ID, Tenant ID
  • Geographic Region: Shows deployment region (e.g., NAM for North America)
  • Portal Type: Template information (e.g., PowerPages_BlankTemplate_V2)
  • Auth Key Expiration: Date when portal authentication key needs renewal
  • Cache Management Tools: Buttons to clear portal cache or config cache (useful for troubleshooting)

Essential for support tickets, troubleshooting, and verifying portal configuration.
